# Security Policy

## Reporting a vulnerability

Please report potential security vulnerabilities privately by emailing
security@sovereigneg.com. Do not report security vulnerabilities through
public GitHub issues, pull requests, or discussions.

This policy applies to the source code in this repository and the official
[`seg-sdk` Python package](https://pypi.org/project/seg-sdk/), including its
published source distributions and wheels.

## What to include

- The affected package version, or the relevant source commit.
- A clear description of the security impact.
- Sanitized steps to reproduce the issue.
- The Python version and operating system when relevant.

Do not include live credentials, API keys, customer data, or unredacted
sensitive logs. Redact authentication headers and replace other secrets with
clearly fake values.

## Coordinated disclosure

Keep vulnerability details confidential until a fix is released and
disclosure is coordinated with SovereignEG.

Thank you for helping us keep this SDK and the systems it interacts with secure.
